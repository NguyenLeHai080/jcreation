# Jcreation Site Setup

Plugin nay tao cau truc ban dau cho website Jcreation:

- Pages: Trang chu, Ve chung toi, San pham, Doi tac thuong mai, Dich vu khach hang, Tin tuc.
- Main Menu gan vao vi tri `primary`, `primary_mobile`, `footer` cua Flatsome.
- Categories: `tin-tuc`, `san-pham`.
- Mot so bai viet mau de lam khung SEO.
- Homepage va Posts page trong Settings > Reading.
- Mau primary cua Flatsome theo xanh logo tam thoi `#2697d8`.
- Tu phien ban 1.1.0, setup import cac anh goc tu `https://jcreation.co.kr/ja/home/` vao Media Library va cap nhat Home theo cau truc gan trang goc: main visual, Catalogue, Video, Product Portfolio, Products, Notice, R&D, footer info.

## Cach dung

1. Vao WordPress Admin > Plugins.
2. Kich hoat `Jcreation Site Setup`.
3. Neu can chay lai, vao Tools > Jcreation Site Setup > Run Jcreation setup.
4. Mo tung page bang Flatsome UX Builder va keo-tha Section/Row/Element theo `docs/jcreation-ux-builder-build-checklist.md`.

## Rang buoc

- Plugin khong them CSS.
- Plugin khong sua theme cha Flatsome.
- Plugin khong dang ky shortcode va khong tao layout bang shortcode thu cong.
- Noi dung page ban dau la HTML sach de co sitemap/noi dung SEO truoc; phan layout can duoc refine bang UX Builder UI.
